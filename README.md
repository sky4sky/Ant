# Ant — Scripting 脚本仓库

> 公开的 Scripting 脚本集合，持续更新。

## 包含脚本

| 脚本 | 说明 |
|------|------|
| 脚本管理工具 | 脚本备份、管理、发布一体化工具 |
| A股看板 | A 股行情看板 |
| AppStore翻译 | App Store 应用翻译 |
| Base64Tool / Base64编解码 | Base64 编码解码工具 |
| PinPlus | 引脚管理 |
| RedeemTunesCode | iTunes 兑换码工具 |
| iTunes Utilities 图文工具 | iTunes 工具集 |
| iTunes Utilities 翻译图文 | iTunes 翻译工具集 |
| 图像标注 | AI 图像标注 |
| 脚本备份 | 脚本备份工具 |

在 Scripting app 中导入 `.scripting` 文件即可使用。
